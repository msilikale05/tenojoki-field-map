# Tenojoki field map

Browser map for fieldwork in the Teno / Deatnu river valley (study areas A1 Karasjok, A2 Utsjoki–Kaldoaivi, A3 Tana bru).

* Open the site on a phone, tap **◎** to start GPS, **➤** to follow, **#** for the UTM 35N 5 km grid.
* Tap a start point → **Navigate here** for live distance and bearing.
* Tap anywhere on the map for that point's coordinates (WGS 84 + UTM 35W).
* Tap **⤓** on Wi-Fi before going out: the Tenojoki map (zoom 8–13) is saved on the phone and works without network.
* "Add to Home screen" installs it like an app.

Map tiles rendered from the QGIS project `North_Finland_OSM.qgz` (theme "Detail – topo").
