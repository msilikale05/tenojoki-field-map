# Tenojoki field map

Browser map for fieldwork in the Teno / Deatnu river valley (study areas A1 Karasjok, A2 Utsjoki–Kaldoaivi, A3 Tana bru).
Open https://msilikale05.github.io/tenojoki-field-map/ on a phone and "Add to Home Screen".

**Map** – Tenojoki map rendered from QGIS (zoom 8–13 whole area, 14 for A1–A3), zoom to 19; at 16+ OpenStreetMap street detail is added when online.
**◎ / ➤** – GPS position (decimal, DMS, UTM 35W, accuracy, altitude, which study area) / follow mode. **#** UTM 35N 5 km grid. **🧭** compass heading.
**● REC** – record a track (distance, moving time, speed, elevation gain); saved on the phone, export GPX / GeoJSON.
**＋ Point** – waypoint at your position (or tap the map → "Add point here") with category, name, note and photo; export GeoJSON / CSV / GPX / photos.
**☰ Field** – tracks, points, share my position (SMS / WhatsApp / copy), emergency 112, battery saver.
**Navigate** – from any start point, waypoint or tapped spot: live distance, bearing and a turn-left/right arrow (compass on).
**⤓** – save the Tenojoki map for offline use (≈ 220 MB, use Wi-Fi). Tracks and points never leave the phone unless you export them.

Keep the screen on while recording: phones pause GPS for web pages when locked.

Tiles rendered from `North_Finland_OSM.qgz` (map theme "Detail – topo").
